📖 TUTORIAL

TANK BATTLES

• Choose tanks on the main menu → Map → Game Mode → Lobby → Fight.

• P1: A/D move · Mouse aim · Hold Space to charge, release to fire.

• P2: Arrow keys move · same mouse aim on their turn (local hot-seat).

• Wind affects shells. Dig the terrain. Collect airdrops for rare shells.

AIR BATTLES

• P1: WASD fly · Space fire · Q/E switch weapon.

• P2: Arrows fly · Enter fire · N/M switch weapon.

• Use Flares to decoy incoming homing missiles.

ALL OUT WAR

• Mix tanks, helis, and jets on one map.

• Tanks: A/D (P1) or Arrows (P2) · Space / Enter to fire · Q/E or N/M switch shell.

• Aircraft: same flight controls as Air Battles.

ACCOUNT & PROGRESS

• Register / login to save coins, upgrades, skins, clan.

• Garage upgrades HP & shell power. Shop unlocks skins & consumables.

• Challenges unlock camo rewards. Dev tools are owner-only.

MULTIPLAYER LOBBIES

• Create a lobby to get a code. Friend joins with the code (same PC / two tabs).

• Both press READY. Host starts → map select → fight. P1 host · P2 guest controls.

• Online cross-internet multiplayer is still planned for a future update.
